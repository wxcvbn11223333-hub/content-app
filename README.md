# مولّد المحتوى — ملفات الرفع (التقني أبو أمير x7m177)

الملفات:
- index.html : واجهة التطبيق
- api/ai.js : دالة سيرفر تخفي مفتاح الذكاء الاصطناعي
- manifest.json + sw.js + الأيقونات : عشان يتثبت كتطبيق باسمك وبشاشة كاملة

## خطوات الرفع (Vercel — الأبسط، وفيه خطة مجانية)
1. سوّ حساب في GitHub وأنشئ مستودع جديد، وارفع كل هذي الملفات فيه (مع الحفاظ على مجلد api).
2. سوّ حساب في Vercel، واختر Add New Project، واربطه بالمستودع، واضغط Deploy.
3. من إعدادات المشروع في Vercel ← Environment Variables أضف:
   - ANTHROPIC_API_KEY = مفتاحك من console.anthropic.com
   - (اختياري) MODEL = اسم نموذج أرخص إذا تبي تقلل التكلفة
4. اعمل Redeploy بعد إضافة المتغيرات، وبيطلع لك رابط ينتهي بـ vercel.app بدون أي هوية غير هويتك.
5. لو عندك دومين، اربطه من Settings ← Domains.

## مهم قبل ما تنشر الرابط
- كل ضغطة "اكتب" عند متابعينك تُحسب عليك من حساب API. حدّد حد صرف شهري من لوحة console.anthropic.com.
- الدالة فيها حد تقريبي ٤٠ طلب في الساعة لكل زائر، لكنه حماية بسيطة وليس مضمون. راقب الاستهلاك أول أيام.
- لا تحط المفتاح داخل index.html أبداً، مكانه فقط في Environment Variables.
- أسماء الأزرار في المواقع قد تختلف شوي عن اللي كتبته هنا.
